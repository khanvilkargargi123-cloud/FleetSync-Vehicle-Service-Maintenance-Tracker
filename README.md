# FleetSync – Vehicle Service & Maintenance Tracker

## 📌 Project Overview

FleetSync is a web-based Vehicle Service and Maintenance Tracking System designed for service centers to manage customers, vehicles, service history, bookings, maintenance schedules, invoices, and service reminders efficiently.

The system provides an easy-to-use admin dashboard for managing vehicle service operations.

## 🎯 Objectives

- Manage customer information
- Manage vehicle information
- Manage service records
- Manage service bookings
- Track vehicle service history
- Manage maintenance schedules
- Generate and manage invoices
- Provide service reminders
- Provide an easy-to-use admin dashboard

## ⚙️ Installation

1. Download or clone this repository.
2. Install XAMPP.
3. Place the FleetSync folder inside the `htdocs` folder.
4. Start Apache and MySQL from XAMPP.
5. Create the required MySQL database.
6. Import the database SQL file.
7. Configure the database connection.
8. Configure email settings using `email_config.example.php`.
9. Open the project in your browser.

Example:

http://localhost/FleetSync/

## 🔐 Security

Sensitive configuration files such as email credentials should not be uploaded to GitHub.

The actual `email_config.php` file should remain private.

Use `email_config.example.php` as a configuration template.
